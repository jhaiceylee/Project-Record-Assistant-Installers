# Project Record Assistant

Download the installer for your computer from the [Releases](https://github.com/jhaiceylee/Project-Record-Assistant-Installers/releases) page.

| Computer | File |
| --- | --- |
| Windows | Project-Record-Assistant-windows-x64.zip |
| Mac with Apple silicon | Project-Record-Assistant-macos-arm64.zip |
| Mac with an Intel processor | Project-Record-Assistant-macos-x64.zip |
| Linux, 64-bit PC | Project-Record-Assistant-linux-x64.tar.gz |
| Linux, ARM | Project-Record-Assistant-linux-arm64.tar.gz |

Windows: unzip the download, then double-click `Install.cmd`.

Mac: unzip the download, open Terminal in that folder, and run `chmod +x Install.command && ./Install.command`.

Linux: unpack the download, open a terminal in that folder, and run `chmod +x install.sh && ./install.sh`.

The terms of use must be accepted before any files are copied.
